# NeuroNexus Internship - Task 1

## 🌐 Project Title: Landing Page (Google Form-like Form)

This project is a clean, responsive, and beautifully styled landing page built using **only HTML and CSS** as part of the **NeuroNexus Web Development Internship**.

---

## 📋 Form Details:
The form collects the following inputs:
- Full Name
- Contact Number
- Address
- Company Name
- Email Address
- Department (Select Menu)
- Gender (Radio Buttons)
- Submit Button

---

## 🎨 Features:
- Attractive gradient background
- Responsive layout
- Hover effects on submit button
- Box-shadow and rounded design
- Clean fonts using Google Fonts (Poppins)
- Pure HTML & CSS – no JavaScript used
